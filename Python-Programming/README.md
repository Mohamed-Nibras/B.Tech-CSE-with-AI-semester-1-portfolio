# Python Practice Scripts – Semester 1

This folder contains structured Python practice programs created during
Semester 1 of the B.Tech CSE (AI) program.

## Folder Structure
- 01_basics – variables, input/output, type casting
- 02_conditionals – if/else logic programs
- 03_data_structures – list, tuple, set, dictionary practice
- 04_loops – for/while loops and pattern problems
- 05_functions – function definitions and return logic
- 06_file_handling – text, CSV, and JSON file operations
- 08_oop – classes, objects, and basic OOP concepts

## Purpose
These scripts were written to strengthen logic building,
syntax familiarity, and problem-solving using Python.
Each file focuses on a single concept for clarity.

## Note on File Selection
Only selected, clean, and representative practice scripts are included
to showcase core concepts clearly. Not all experimental or repetitive
practice files are part of this repository.
