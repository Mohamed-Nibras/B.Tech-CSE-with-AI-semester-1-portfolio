# Logic & Problem Solving – Semester 1

This folder represents my structured journey of improving logical thinking and problem-solving skills using Python during Semester 1 of B.Tech CSE (AI).

---

## Overview

The primary focus of this track was to develop a strong problem-solving mindset, rather than just writing code.

The approach emphasized:
- Understanding problems deeply
- Breaking them into smaller steps
- Identifying patterns
- Writing clean and structured solutions

---

## Folder Structure

### Selected Problems
Contains individual problem-solving exercises covering common patterns such as:
- Pattern printing
- String manipulation
- Recursion
- Basic algorithms

### Systems
Contains small systems built by combining multiple concepts:
- Expense Categorizer
- Student Marks Analyzer
- Number Evaluator
- Word Frequency Toolkit

---

## Problem Solving Framework

A structured approach was developed and consistently applied:

1. Understand the problem
2. Identify inputs and outputs
3. Break into smaller steps
4. Dry run manually
5. Write a rough approach
6. Implement the solution
7. Test and refine

---

## Key Learnings

- Thinking before coding is critical
- Breaking problems into steps simplifies complexity
- Identifying patterns improves efficiency
- Debugging becomes easier with structured logic
