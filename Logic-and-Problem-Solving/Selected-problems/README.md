# Selected Problems – Logic & Problem Solving

This folder contains selected Python problems solved as part of my Semester 1 journey in improving logical thinking and problem-solving skills.

The focus was not just on coding, but on understanding patterns, breaking problems into steps, and writing clean, structured solutions.

---

## Problems Covered

- Pattern Printing
- Palindrome Checker
- Anagram Checker
- Caesar Cipher Encryption (Basic)
- Fibonacci Sequence (Recursion)
- Pascal’s Triangle

---

## Concepts Used

- Loops and conditionals
- String manipulation
- Recursion
- Basic algorithms
- Pattern recognition

---

## Approach Used

Each problem was solved using a structured framework:

1. Understand the problem
2. Identify inputs and outputs
3. Break into smaller steps
4. Dry run manually
5. Write a rough approach
6. Implement the solution
7. Test and refine

---

## Purpose

The goal of these problems was to:
- Improve logical thinking
- Recognize common problem patterns
- Practice clean coding
- Build problem-solving confidence
