# Systems – Logic & Problem Solving

This folder contains small Python-based systems built by combining multiple programming concepts.

These are not just individual problems, but mini systems designed to simulate real-world logic and workflows.

---

## Systems Included

### 1. Expense Categorizer
- Categorizes expenses by type
- Calculates total and category-wise spending
- Uses dictionaries and loops

### 2. Student Marks Analyzer
- Calculates average marks
- Finds highest score
- Counts passing students
- Demonstrates data processing and aggregation

### 3. Number Evaluator
- Evaluates properties of numbers (e.g., even/odd, conditions)
- Uses conditional logic

### 4. Word Frequency Toolkit
- Counts occurrences of words
- Demonstrates dictionary usage and text processing

---

## Concepts Used

- Functions
- Dictionaries
- Lists
- Loops and conditionals
- Input handling
- Basic data processing

---

## Design Approach

Each system was built with a focus on:
- Breaking problems into smaller tasks
- Writing reusable logic
- Using appropriate data structures
- Keeping the code readable and simple

---

## Purpose

These systems helped in:
- Applying multiple concepts together
- Moving from problem-solving to system thinking
- Building real-world logic
- Improving structured coding

---

## Note

These systems are intentionally CLI-based to focus on logic rather than UI.
