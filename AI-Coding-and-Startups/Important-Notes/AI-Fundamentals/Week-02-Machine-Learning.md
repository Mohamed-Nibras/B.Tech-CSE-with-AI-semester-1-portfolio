# Week 2 — Introduction to Machine Learning

## 🎯 Objective

To understand how Machine Learning systems learn from data and explore practical ML demonstrations.

---

## 🧠 Topics Covered

### Machine Learning Types

#### Supervised Learning

Uses labeled data to learn patterns.

Examples:

* Classification
* Prediction

---

#### Unsupervised Learning

Uses unlabeled data to discover hidden structures.

Examples:

* Clustering
* Grouping

---

#### Reinforcement Learning

Learns through rewards and penalties.

Examples:

* Robotics
* Game AI

---

### Machine Learning Workflow

Typical ML pipeline:

1. Collect Data
2. Prepare Data
3. Train Model
4. Evaluate Model
5. Make Predictions

---

### Applications of Machine Learning

Machine Learning is used in:

* Recommendation systems
* Search engines
* Medical diagnosis
* Finance
* Fraud detection
* Autonomous systems

## 🎯 Key Learnings

* Machine Learning systems learn from data.
* Data quality directly affects model performance.
* Different ML approaches solve different problems.
