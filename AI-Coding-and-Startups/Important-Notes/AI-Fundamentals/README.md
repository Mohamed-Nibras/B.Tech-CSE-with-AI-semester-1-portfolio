## 🎯 Key Learnings

Throughout these weeks I learned:

* AI is the broader field of creating intelligent systems.
* Machine Learning is a subset of AI that learns from data.
* Deep Learning is a subset of Machine Learning that uses neural networks.
* Most AI systems depend on data, pattern recognition, prediction, and decision making.
* Different machine learning approaches solve different types of problems.
* AI systems are already integrated into many real-world applications.
