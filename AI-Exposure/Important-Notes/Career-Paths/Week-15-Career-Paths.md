# Week 15 — Coding Career Paths

## 🎯 Topic

Coding Career Paths: Software Engineer, Machine Learning Engineer, Data Scientist, and AI Engineer

## 📌 Objective

Understand the major technology career paths, compare their responsibilities, identify required skills and tools, and explore which paths align most closely with personal interests.

---

# 💻 Software Engineer (SWE)

## Main Responsibilities

- Build software applications
- Develop websites
- Create backend systems
- Build automation tools
- Maintain and improve software products

## Skills Required

- Python
- Java
- JavaScript
- Data Structures & Algorithms
- Problem Solving
- Database Management
- Frontend Development
- Backend Development
- Git and GitHub

## Common Tools

- VS Code
- Git
- GitHub
- Docker
- Linux
- PostgreSQL
- MySQL

## Key Observation

Software Engineering forms the foundation of many technology careers and provides strong problem-solving and system design skills.

---

# 🤖 Machine Learning Engineer (MLE)

## Main Responsibilities

- Train machine learning models
- Deploy models into production
- Optimize model performance
- Maintain ML systems
- Scale ML infrastructure

## Skills Required

- Python
- Machine Learning
- Deep Learning
- Model Deployment
- Git
- Linux
- Bash
- Cloud Computing

## Common Tools

- TensorFlow
- PyTorch
- Docker
- GitHub
- AWS
- Google Cloud Platform (GCP)
- MLflow

## Key Observation

Machine Learning Engineering combines software engineering with advanced machine learning and often requires significant mathematical depth.

---

# 📊 Data Scientist

- Generate insights
- Support business decisions
- Create reports and visualizations

## Skills Required

- Statistics
- Probability
- Python
- R
- SQL
- Data Analysis
- Data Visualization

## Common Tools

- Jupyter Notebook
- Pandas
- NumPy
- SQL
- Tableau
- Power BI
- Matplotlib

## Key Observation

Data Science focuses on transforming data into meaningful insights that help organizations make better decisions.

Before this week, I had a general understanding of technology careers.

- The tools used by professionals
- How careers overlap
