# Week 05 – Beginner AI Projects and No-Code Machine Learning

## 🎯 Topic

Exploring beginner AI projects using no-code and low-code machine learning tools.

---

## 🔬 Tools Explored

### Teachable Machine

Created image classification models using webcam images.

### Lobe

Built and trained machine learning models through a visual interface.

---

## 🧪 Experiments Performed

### Experiment 1

Two-Class Model

Classes:

- Thumbs Up
- Thumbs Down

Observations:

- Small datasets caused inconsistent predictions.
- Larger datasets improved stability and accuracy.

---

### Experiment 2

Three-Class Model

Classes:

- Pen
- Paper
- Eraser

Observations:

- More training examples improved performance.
- Similar-looking objects increased confusion.
- Lighting conditions affected results.
- Background changes affected predictions.

---

## 🧠 Key Machine Learning Concepts Learned

### Dataset Quality

More examples generally improve accuracy.

### Data Diversity

Different poses, backgrounds, and lighting improve model robustness.

### Classification

Machine learning models learn patterns that help classify inputs into categories.

### Model Improvement

Performance improves through additional training examples and feedback.
