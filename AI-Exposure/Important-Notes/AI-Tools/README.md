# 🤖 AI Tools

This chapter documents my exploration of modern AI tools and platforms during Semester 1.

The focus was understanding how AI systems work, how developers and creators use them, and how these tools are shaping software development, creativity, and product building.

---

## 🎯 Objective

To understand:

- Conversational AI systems
- AI image generation
- AI coding assistants
- No-code machine learning tools
- GitHub and AI repositories
- Builder tools used by startups and founders

## 🧠 Key Learnings

- AI tools are productivity multipliers rather than replacements for human thinking.
- Modern AI systems can generate text, images, and code.
- Machine learning models improve with larger and more diverse datasets.
- GitHub is an important platform for collaboration and project management.
- Product success depends on solving real user problems.
- User trust and clarity are often more valuable than adding more features.
