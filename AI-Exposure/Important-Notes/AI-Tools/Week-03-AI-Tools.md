# Week 03 – Understanding Modern AI Tools

## 🎯 Topic

How AI tools like ChatGPT, DALL·E, and GitHub Copilot work.

---

## 🤖 ChatGPT

### What is ChatGPT?

ChatGPT is a conversational AI system designed to understand natural language and generate human-like responses.

### Topics Explored

- What ChatGPT is
- Why ChatGPT became globally popular
- Challenges of conversational AI
- Natural language understanding
- Neural networks
- Brain-inspired AI architecture
- Unsupervised learning
- Supervised learning
- ChatGPT vs Humans

### Key Insights

- Human language contains ambiguity and context.
- AI researchers spent decades trying to solve conversational AI.
- Neural networks were inspired by biological neurons.
- ChatGPT predicts the most likely next words based on patterns learned from large datasets.

---

## 🎨 DALL·E

### What is DALL·E?

DALL·E is an AI system that generates images from text descriptions.

### Topics Explored

- GPT-2
- GPT-3
- Image GPT
- DALL·E evolution
- Text-to-image generation
- Artistic image creation
- Physical realism in generated images

### Key Insights

- AI can generate completely new images from text prompts.
- DALL·E combines language understanding and image generation.
- Prompt quality directly affects output quality.
- AI-generated images can be creative and highly customizable.

---

## 💻 GitHub Copilot

### What is GitHub Copilot?

GitHub Copilot is an AI coding assistant that suggests code while developers write programs.

### Topics Explored

- How Copilot works
- Code completion
- Productivity improvements
- Benefits and limitations
- Future of AI-assisted programming

### Key Insights

- Copilot speeds up development.
- Developers must still verify generated code.
- AI assists coding but does not replace software engineering fundamentals.

Week 3 introduced the three major forms of generative AI:

- Text Generation → ChatGPT
- Image Generation → DALL·E
- Code Generation → GitHub Copilot
