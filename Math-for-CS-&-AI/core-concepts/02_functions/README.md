# Functions

## Concept
A function is a relation where each input maps to exactly one output.

---

## Key Concepts

- **Domain**  
  Set of all possible input values  

- **Range**  
  Set of output values  

- **One-One (Injective)**  
  Different inputs produce different outputs  

- **Onto (Surjective)**  
  Every value in the range is mapped  

- **Bijective**  
  Both one-one and onto  

---

## Python Application

Functions in Python are reusable blocks of code used to perform specific tasks.

---

## Example

```python
def square(x):
    return x * x

print(square(4))  # 16

```

---

## Use in Computer Science

- Code reusability and modularity
- Breaking complex problems into smaller parts
- Building scalable and maintainable systems

---

## Summary

- Functions are essential for structuring programs, enabling reuse of logic, and simplifying complex problem solving in both mathematics and computer science.
