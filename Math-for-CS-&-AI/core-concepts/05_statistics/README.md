# Statistics

## Concept
Statistics is used to analyze, summarize, and interpret data.

---

## Key Measures

- **Mean**  
  Average of all values  

- **Median**  
  Middle value after sorting  

- **Mode**  
  Most frequent value  

- **Variance**  
  Measure of how far values are spread from the mean  

---

## Python Application

Statistics can be implemented using basic loops and calculations.

---

## Example

```python
data = [10, 20, 30, 40]

mean = sum(data) / len(data)
maximum = max(data)

count_above_mean = 0
for x in data:
    if x > mean:
        count_above_mean += 1

print(mean, maximum, count_above_mean)

```
