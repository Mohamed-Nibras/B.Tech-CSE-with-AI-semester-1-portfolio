# Logic Gates

## Concept
Logic gates are fundamental building blocks of digital systems that perform operations on binary inputs (True/False or 1/0).

---

## Basic Gates

- **AND Gate**  
  Output is true only if both inputs are true  

- **OR Gate**  
  Output is true if at least one input is true  

- **NOT Gate**  
  Reverses the input value  

---

## Truth Table Example (AND Gate)

| A | B | A AND B |
|---|---|--------|
| T | T | T      |
| T | F | F      |
| F | T | F      |
| F | F | F      |

---

## Python Application

Logical operations can be implemented using conditional statements.

---

## Example

```python
A = True
B = False

print(A and B)  # False
print(A or B)   # True
print(not A)    # False

```
