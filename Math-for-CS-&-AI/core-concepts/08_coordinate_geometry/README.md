# Coordinate Geometry

## Concept

Coordinate geometry studies points, lines, and shapes using a coordinate system.

---

## Key Concepts

- **Distance Formula**  
  Distance between two points:
  √((x2 - x1)² + (y2 - y1)²)

- **Slope of a Line**  
  (y2 - y1) / (x2 - x1)

- **Equation of Line**  
  y = mx + c  

---

## Example

```python
import math

x1, y1 = 1, 2
x2, y2 = 4, 6

distance = math.sqrt((x2 - x1)**2 + (y2 - y1)**2)
print(distance)

```
