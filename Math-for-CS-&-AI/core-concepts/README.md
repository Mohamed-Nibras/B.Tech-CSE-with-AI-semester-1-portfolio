# Core Concepts – Math for CS

This folder contains the fundamental mathematical concepts studied as part of the Semester 1 Math for Computer Science track.

---

## Overview

The focus of this section is to build clear and precise understanding of core topics that form the foundation for problem solving and programming.

Each concept is presented with:
- Simple and accurate definitions  
- Key ideas and properties  
- Python-based examples  
- Relevance to computer science  

---

## Topics Covered

- Sets  
- Functions  
- Matrices and Determinants  
- Probability  
- Statistics  
- Logic Gates  
- Permutations and Combinations  
- Coordinate Geometry  

---

## Approach

Each topic was studied using a structured method:

1. Understand the concept  
2. Define it clearly in one line  
3. Identify key properties  
4. Apply using simple Python examples  
5. Connect to real-world or CS use cases  

---

## Purpose

The goal of this section is to:
- Build strong conceptual clarity  
- Improve precision in definitions  
- Develop the ability to explain concepts clearly  
- Create a foundation for advanced topics
