# Python Projects – Semester 1

This folder contains selected Python projects developed during Semester 1 of the B.Tech CSE (AI) program.

These projects were built to apply programming concepts, logical thinking, problem solving, file handling, recursion, data management, and system design principles learned throughout the semester.

---

## Projects Included

### 1. Expense Tracker (CLI)

A command-line expense management application that allows users to:

* Record expenses
* Store data persistently
* View spending summaries
* Track financial records

Concepts Used:

* Functions
* File Handling
* Loops and Conditionals
* Input Validation
* Basic Error Handling

---

### 2. Logic Solver App

A collection of logic-based mini games and exercises designed to strengthen analytical thinking and problem-solving skills.

Features:

* Interactive logic challenges
* Score tracking
* Persistent data storage
* Multiple problem-solving exercises

Concepts Used:

* Functions
* Modular Programming
* File Handling
* Logic Building
* Data Persistence

---

### 3. Maze Solver (Recursion + Backtracking)

A maze-solving application built using recursive Depth First Search (DFS) and backtracking techniques.

Features:

* Automatic maze solving
* Path exploration
* Recursive traversal
* Visual maze output

Concepts Used:

* Recursion
* Backtracking
* DFS Algorithm
* State Tracking
* Algorithmic Problem Solving

---

### 4. Student Management System

A command-line application for managing student records with persistent storage.

Features:

* Add student records
* Update records
* Delete records
* Search functionality
* Data persistence

Concepts Used:

* Object-Oriented Programming (OOP)
* CSV File Handling
* CRUD Operations
* Data Validation
* Structured Program Design

Only selected projects have been included in this portfolio.

* Learning value
* Practical application
* Problem-solving depth
* Concept coverage
* Overall implementation quality

Smaller practice exercises and repetitive implementations have intentionally been excluded to maintain focus on representative work.
