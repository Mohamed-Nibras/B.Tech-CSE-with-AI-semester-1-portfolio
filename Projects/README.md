# Python Mini Projects – Semester 1

This folder contains Python mini projects developed during
Semester 1 of the B.Tech CSE (AI) program.

Each project is designed as a self-contained, console-based application
to strengthen core Python concepts, logic building, and system-level thinking.

## Projects Included

### 1. Expense Tracker (CLI)
A command-line based expense tracking application that allows users to:
- Record daily expenses
- Persist data using file handling
- View and calculate total expenses

Concepts used:
- Functions
- File handling
- Loops and conditionals
- Input validation
- Basic error handling

### 2. Student Management System (CLI)
A command-line based system to manage student records with full CRUD support.

Concepts used:
- Object-Oriented Programming (OOP)
- CSV file handling
- Data validation
- In-memory data management with persistent storage

## Project Documentation
Each project is organized in its own folder and includes a dedicated
README file with:
- Feature overview
- Design explanation
- Technologies used
- Execution instructions
- Future improvement ideas

## Purpose
These mini projects represent the practical application of Python concepts
learned during Semester 1 and focus on clarity, correctness, and clean structure.
