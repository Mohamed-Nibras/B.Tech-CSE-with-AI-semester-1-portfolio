# 🧠 Logic Solver App – Mini Project 1

A command-line based **Logic Solver App** built using Python.

This application contains multiple mini-games designed to improve **logic building, problem solving, and Python fundamentals**, while also demonstrating **modular design and persistent data storage**.

---

## 🚀 Features

### 🎯 Included Games

- 🔢 Number Guessing Game
- 📃 Math Quiz Game
- 🧩 Number Puzzle Game

### ⚙️ System Features

- Menu-driven CLI interface
- Score tracking for each game
- Persistent score storage using file handling (`scores.txt`)
- Input validation & error handling
- Clean modular function-based design

---

## 🛠️ Technologies Used

- Python 3
- Functions
- Loops & Conditionals
- Random module
- File Handling
- Sets (to avoid repeated questions)
- Input validation
- CLI UI formatting

---

## ▶️ How to Run

1. Make sure Python 3 is installed
2. Open terminal inside this project folder
3. Run:

```bash
python logic_solver_app.py
```

---

## 🎮 Game Rules

🔢 Number Guessing

1. Guess a number between 1–30
2. 5 attempts maximum
3. Score = remaining attempts

📃 Math Quiz

1. 5 random math questions
2. +, −, ×, ÷ operations
3. Supports decimals (float answers)
4. Score = number of correct answers

🧩 Number Puzzle

1. Identify the missing number in a sequence
2. Patterns include:
   - Addition
   - Multiplication
   - Squares
3. 5 puzzles total
