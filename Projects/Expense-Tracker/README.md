# Expense Tracker (Mini Project 1)

A simple command-line based Expense Tracker built using Python.  
This project allows users to record daily expenses, view past expenses, and calculate total spending with data stored persistently in a file.

---

## 📌 Features
- Add expenses with **date, amount, category, and description**
- Automatically saves data to a file (`expenses.txt`)
- Loads previous expenses on program restart
- View all recorded expenses
- Calculate total amount spent
- Input validation for numeric values
- Menu-driven command-line interface

---

## 🛠️ Technologies Used
- Python 3
- File Handling (`.txt`)
- Functions
- Loops and Conditionals
- Basic Error Handling
- Python Standard Library (`datetime`)

---

## ▶️ How to Run
1. Ensure Python 3 is installed on your system
2. Clone the repository or download this project folder
3. Open a terminal in this directory
4. Run the program:
   ```bash
   python expense_tracker.py
   ```
